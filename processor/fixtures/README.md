# T06 synthetic PDF sources

These three documents were authored for VectorNext with ReportLab and a rendered DejaVu Sans text image. They contain fictional valve records and a deliberately uninterpreted diagram. They are covered by the repository license; they are not operating instructions.

- `mixed_regions.pdf`: native text and an embedded scanned text region on one page; V8/24 kPa, V9/31 kPa, batch MIX-007, and 14-day closing note.
- `mixed_overlay.pdf`: raster text plus an invisible text layer for the same line; V5/19 kPa. Current Docling omits the invisible layer and obtains the line once with OCR.
- `uninterpreted_graphic.pdf`: readable title/caption and a diagram with no extracted semantics. Its artifact must be partial.

All three pages were rendered and visually inspected. `processor/build_fixtures.py` is an explicit authoring helper; tests never run it or change source PDFs. Authoring uses the processor image's DejaVu Sans font and ReportLab 4.4.9. Tool/font upgrades require renewed visual review; hashes are bound by the captured extraction artifacts.

The original native two-page guide and scanned note are reused read-only from `evals/fixtures/`. No evaluation source or gold label is regenerated by T06 checks. Rust test artifacts in `tests/fixtures/pdf/` are captured parser outputs, not answer labels. Their JSON is intentionally readable for source/geometry inspection.
