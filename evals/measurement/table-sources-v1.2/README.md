# Development table sources

These are exact copies of the 32 JSON table documents in the original T39
development proposal. They contain all retained original cells and paragraphs,
with the original adapter's repeated first-row `headers` field. They contain no
sealed documents or questions. `manifest.json` records byte counts and SHA-256.

Source: Zhu et al. (2021), **TAT-QA**, distributed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
[Pinned upstream dataset](https://github.com/NExTplusplus/TAT-QA/blob/870accc41953dcde885aabeb963d94aabdc0fbc3/dataset_raw/tatqa_dataset_dev.json)
and [source lock/attribution](../public-sources.json).

The upstream flattened table/paragraph arrays were adapted into JSON records by
the original proposal builder. Publisher PDF geometry and report-family identities
have not been verified. The new adapter produces a separate representation; it
never rewrites these files. See [the policy](../table-context-v1.2.md).
